Course home

Operate Akamai from a Windows shell

Ten short lessons: install and authenticate, then find and change properties, wire hostnames into security configs, manage client lists and custom rules, and administer users — all from PowerShell.

How to use this course. Work top to bottom the first time — each lesson builds on the last. After that, jump straight to whatever task you need. Every lesson links back here (the Course home link in its footer) and to the next one. Keep the cheat sheet open while you work.
